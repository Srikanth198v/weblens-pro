# WebLens Pro

WebLens AI - Product Requirements Document (PRD)



Volume 1: Product Vision & Design System



You are a senior product designer, UI/UX designer, frontend architect, and branding expert. Your mission is to design a premium SaaS product called WebLens AI. This document establishes the foundation for the entire application. Every future page must follow these rules consistently.



---



Product Overview



WebLens AI is a premium website analysis platform.



The goal is not simply to generate scores. The goal is to make users feel like they are receiving a professional website consultation from a high-end design agency.



The application should communicate trust, professionalism, intelligence, simplicity, and premium quality.



The overall experience should feel modern, elegant, smooth, and memorable.



Users should immediately think:



«"This feels like software used by professionals."»



---



Target Audience



- Freelancers

- Startup founders

- Designers

- Developers

- Agencies

- Small businesses

- Students learning web development

- Portfolio creators



---



Design Philosophy



The interface should combine inspiration from:



- Apple

- Linear

- Stripe Dashboard

- Framer

- Notion



Do not copy any company.



Instead, create an original interface inspired by their simplicity and attention to detail.



The interface must avoid unnecessary clutter.



Everything should feel spacious and carefully organized.



Every element must have a clear purpose.

Typography



Use a clean modern font.



Recommended:



Inter



or



Plus Jakarta Sans



Use a clear visual hierarchy.



Large headlines.



Comfortable spacing.



Readable body text.



Never use decorative fonts.



---



Border Radius



Rounded corners.



Modern.



Not overly rounded.



Consistent throughout the application.



---



Shadows



Soft



Elegant



Subtle



Never heavy.



Cards should appear to float slightly above the background.



---



Icons



Use a clean modern icon system.



Simple outlines.



Consistent sizing.



No cartoon icons.



---



Spacing



Use generous spacing.



Every section should breathe.



Avoid crowded layouts.



Maintain a premium appearance.

Mobile Friendly

Performance

User Experience Goals



The application should feel effortless.



The interface should never confuse users.



Every action should feel obvious.



Every screen should guide the user naturally.



Reduce cognitive load.



Prioritize clarity over complexity.

Professional dashboards.

Design Rules



Every page must feel like part of one complete product.



Use consistent spacing.



Use consistent typography.



Use consistent colors.



Use consistent button styles.



Use consistent card layouts.



Never randomly change design styles between pages.
